# LocalMusic Website

Official website, support resources, and legal pages for **LocalMusic** — an offline audio player for iOS.

## Pages

- `index.html` - Homepage with app overview and feature highlights
- `privacy.html` - Privacy Policy (App Store Guideline 5.1.1 compliant)
- `support.html` - Customer Support, FAQs, and troubleshooting guide (App Store Guideline 1.5 compliant)
- `terms.html` - Terms of Use and auto-renewable subscription terms (App Store Guideline 3.1.2 compliant)
- `styles.css` - Styling and responsive design system
- `app.js` - Dynamic year and navigation scripts

## GitHub Pages Deployment

To enable GitHub Pages:
1. Go to your repository **Settings** on GitHub.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment > Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**.

Your website will be available at:
`https://krk-8.github.io/localmusic-website/`
